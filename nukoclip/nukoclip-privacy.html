Privacy Policy for Nukoclip

Last updated: [DATE]

Nukoclip ("the app") is a drawing/illustration app for Android, developed by wildheit ("we", "our"). This page explains what data the app does — and does not — collect.

Short version

Nukoclip does not collect, store, or transmit any personal data. The app has no internet access permission, contains no analytics, no advertising, and no third-party tracking SDKs. Everything you draw and every file you save stays on your device, in a location you choose.

What the app does with your files

Nukoclip reads and writes files only when you explicitly ask it to, through Android's built-in file picker (the Storage Access Framework). For example: saving a drawing, exporting a PSD, or importing an image as a layer. The app does not scan, index, or access any files you have not directly chosen through that picker, and it never uploads any file anywhere — there is no server for it to upload to.

Permissions

Nukoclip does not request the INTERNET permission or any storage permission. All file access goes through the system file picker described above, which does not require a permission grant.

Data collection and analytics

We do not collect:

  • Personal information (name, email, location, etc.)
  • Usage analytics or crash reports sent to any server
  • Advertising identifiers
  • Any data at all, from anyone, including children

Standard Android system logs generated during a crash stay on your device and are only visible to you (or to us if you voluntarily choose to send them to us, e.g. by email, when reporting a bug).

Third-party services

Nukoclip does not integrate any third-party SDK, analytics platform, ad network, or cloud service. It works fully offline.

Children's privacy

Because the app collects no data from anyone, it does not knowingly collect any information from children under 13 (or the relevant age in your country).

Changes to this policy

If this policy ever changes — for example, if a future optional feature introduces network access — this page will be updated and the "Last updated" date above will change accordingly. Any such change would also be reflected in the app's in-app description before release.
