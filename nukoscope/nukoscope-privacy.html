Privacy Policy for NukoScope

Last updated: 15 Sep 2026

NukoScope ("the app") is an Android app, developed by Nuko ("we", "our"), that overlays pinyin/zhuyin readings on Chinese text seen through the camera. This page explains what data the app does — and does not — handle.

Short version

The app's core features — live pronunciation overlay on the camera view, reading a captured still frame, and switching between Pinyin and Zhuyin — all run entirely on your device using a built-in dictionary and send nothing anywhere. Data only ever leaves your device through one optional feature, and only if you explicitly turn it on:

  • AI-assisted reading accuracy (detail screen only): if you enter your own Gemini API key in Settings, the captured still image is sent directly from your device to Google's Gemini API, using your own key, and a more accurate reading is sent back. We do not operate any server, and we never receive or store this image ourselves.

How the app uses your camera

The app's core feature is not possible without a camera, so it requests the CAMERA permission. Recognizing text from the live camera feed or a captured still frame (to overlay readings) is done entirely on your device using Google's ML Kit (on-device text recognition), and the image is never sent anywhere — except through the optional AI accuracy feature described above, if you've enabled it.

What's stored on your device

Your display settings (Pinyin/Zhuyin) and any Gemini API key you enter are stored only in the app's local storage on your device. None of this is sent anywhere, other than through the optional AI accuracy feature described above, if you've enabled it.

Permissions

  • Camera (CAMERA): used for the app's core features — the live pronunciation overlay and capturing a still frame.
  • Internet (INTERNET): used only for the optional AI reading-accuracy feature above. Every other feature works fully offline.

Data collection and analytics

We do not collect:

  • Personal information (name, email, location, etc.)
  • Usage analytics or crash reports sent to any server
  • Advertising identifiers (the app contains no ads)
  • Any data at all, from anyone, including children (other than the Gemini API / ML Kit interactions described above)

Third-party services

The app integrates with exactly two third-party services, both provided by Google and each governed by its own privacy policy:

  • Google ML Kit (text recognition, fully on-device with no network transmission)
  • Google Gemini API (only when the AI accuracy feature is enabled, using your own API key, communicating directly from your device)

No other third-party SDK, analytics platform, or ad network is included.

Children's privacy

Other than through the AI accuracy feature when you've enabled it with your own API key, the app collects no data from anyone. It therefore does not knowingly collect any information from children under 13 (or the relevant age in your country).

Changes to this policy

If this policy ever changes — for example, due to a future feature such as saving scan records — this page will be updated and the "Last updated" date above will change accordingly. Any such change would also be reflected in the app's in-app description before release.
